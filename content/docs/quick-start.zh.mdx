## 开始前准备

你需要一个能够正常接收邮件的邮箱。如果要使用完整知识能力和 WorkBuddy 连接，还需要有效的 OneWorkOS 会员权益。

## 第一次使用

<Steps>

### 创建或登录账号

前往[注册页面](/auth/register)创建账号；已有账号可直接[登录](/auth/login)。注册后按邮件提示完成邮箱验证。

### 确认会员权益

在[会员页面](/pricing)开通会员，或登录后在 [OneWorkOS 设置](/settings/onework)输入收到的兑换码。

### 安装并连接 WorkBuddy

进入 [OneWorkOS 连接页面](/onework)，复制当前安装指令并交给 WorkBuddy 执行，然后从 WorkBuddy 发起网页授权。

### 说出一个真实目标

直接描述你想完成什么，并补充当前进度。例如：“我刚开小红书店，下一步应该做什么？”

### 查看结果并确认下一步

检查文字、图片、视频入口和资料出处。需要连接工具或执行关键操作时，由你确认后继续。

</Steps>

<Callout type="warn">
不要在对话中发送密码、验证码、完整 API Key 或其他敏感信息。请只在受信任的登录或授权页面中输入这些内容。
</Callout>

## 推荐的第一次测试

- “我想使用 WorkBuddy 制作 PPT，应该从哪里开始？”
- “小红书店铺怎么设置发货？我现在还没有配置物流。”
- “请根据官方资料告诉我下一步，并标注出处。”

WorkBuddy 的当前推荐连接方式不需要你复制 API Key。详细流程请查看[连接 WorkBuddy](/docs/workbuddy-connection)。
