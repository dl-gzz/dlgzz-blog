## 知识检索会返回什么

OneWorkOS 会根据你的目标和当前阶段，只检索本次问题需要的内容。结果可能包含：

- 清晰的文字答案和下一步操作
- 官方截图或图文教程
- 视频教程入口
- 资料来源和出处
- 可以继续调用的 WorkBuddy、Skill 或连接器

## 如何提出更有效的问题

一个完整问题最好包含四项信息：

1. **目标**：你想完成什么
2. **阶段**：现在进行到哪一步
3. **现象**：遇到了什么提示或问题
4. **限制**：设备、平台或时间等条件

例如：

> 我已经连接 WorkBuddy，想设置每天自动生成日报。请优先给我具体步骤和资料出处。

## 如何授权

当前 one-worker-os 使用 OAuth 网页授权。安装完整插件或导入 MCP 配置后，在当前 AI 客户端的连接器页面点击“连接/登录”，浏览器会打开授权页；核对账号和权限后，由你本人点击“允许连接”。

不要在聊天中索要、粘贴或展示 API Key、设备 ID、Token 或其他访问凭证。连接失败时，请报告客户端显示的实际状态，检查会员权益并使用“重连”或重启客户端，不要切换到旧版安装器。

## 检索额度

当前 OneWorkOS 会员每月包含 1000 次知识检索。具体使用量和权益状态以账号页面显示为准。
