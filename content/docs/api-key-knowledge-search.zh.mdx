## 知识检索会返回什么

OneWorkOS 会根据你的目标和当前阶段，只检索本次问题需要的内容。结果可能包含：

- 清晰的文字答案和下一步操作
- 官方截图或图文教程
- 视频教程入口
- 资料来源和出处
- 可以继续调用的 WorkBuddy、Skill 或连接器

## 如何提出更有效的问题

一个完整问题最好包含四项信息：

1. **目标**：你想完成什么
2. **阶段**：现在进行到哪一步
3. **现象**：遇到了什么提示或问题
4. **限制**：设备、平台或时间等条件

例如：

> 我刚开通小红书店铺，还没有配置物流。我想设置发货地址，请优先给我官方步骤和出处。

## API Key 是什么

API Key 用于识别调用身份、校验知识权限和计算使用额度。它属于敏感凭证，应像密码一样保护。

<Callout type="info">
使用当前 WorkBuddy 插件时，推荐通过网页授权连接，不需要查看、复制或手动填写 API Key。账号页面没有 API Key 入口通常是正常情况。
</Callout>

只有在明确支持的高级集成或兼容流程中，系统才会使用 API Key。此时请遵守：

- 不要把完整 Key 发到聊天、截图、工单或公开代码仓库
- 不要写入前端网页或可公开下载的文件
- 怀疑泄露时立即停用或撤销对应凭证
- 调用失败时检查会员状态、授权范围、剩余额度和网络连接

## 检索额度

当前 OneWorkOS 会员每月包含 1000 次知识检索。具体使用量和权益状态以账号页面显示为准。
