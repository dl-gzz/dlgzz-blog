## 账号与密码

<Accordions>
<Accordion title="为什么换一台电脑后登录不上？">

账号数据和会员权益保存在云端，不会绑定某一台电脑。请确认使用的是原注册邮箱；如果密码不正确，可通过[找回密码](/auth/forgot-password)设置新密码。

</Accordion>

<Accordion title="为什么收不到注册或重置密码邮件？">

检查邮箱地址是否填写正确，并查看垃圾邮件、订阅邮件或拦截记录。等待几分钟后只申请一次新邮件，避免多次申请导致旧链接失效。

</Accordion>

<Accordion title="为什么重置链接无效、已使用或已过期？">

重置链接具有时效性，并且通常只能使用一次。重新申请后只使用最新邮件中的链接；如果已经成功重置，请直接用新密码登录。

</Accordion>
</Accordions>

## 会员与设备

<Accordions>
<Accordion title="会员权益会跟随账号吗？">

会。会员、知识额度和新增知识包权益属于账号。更换电脑时登录同一个账号即可。

</Accordion>

<Accordion title="更换电脑后如何继续使用 WorkBuddy？">

在新电脑安装 WorkBuddy，登录同一个 OneWorkOS 账号，然后重新安装插件并从 WorkBuddy 发起网页授权。新版插件不需要生成新的设备绑定。

</Accordion>

<Accordion title="兑换码为什么不能使用？">

确认兑换码没有被其他账号使用，并检查当前登录账号是否正确。每枚兑换码只能绑定一个账号，结果以账号页面提示为准。

</Accordion>
</Accordions>

## WorkBuddy 与知识检索

<Accordions>
<Accordion title="为什么 WorkBuddy 连接不上？">

确认会员有效、插件已经安装，并且授权是从 WorkBuddy 的 `one-worker-os` 连接器发起。不要在浏览器直接打开 `/mcp`。

</Accordion>

<Accordion title="为什么没有看到 API Key？">

当前 WorkBuddy 推荐使用网页授权，不要求用户复制 API Key。账号页面没有 API Key 入口并不影响正常连接和检索。

</Accordion>

<Accordion title="为什么知识检索失败或没有结果？">

检查网络、会员状态、授权连接和剩余额度。重新提问时补充目标、当前阶段、页面提示和期望结果，但不要发送密码或验证码。

</Accordion>

<Accordion title="答案与当前平台页面不一致怎么办？">

先查看答案中的资料出处和更新时间。平台规则可能变化，涉及账户、资金、资质、发布或订单的操作，应以最新官方页面为准。

</Accordion>
</Accordions>

## 反馈问题时提供什么

请提供脱敏后的错误提示、操作步骤、设备系统、使用的功能和大致发生时间。请隐藏密码、验证码、完整 API Key、兑换码和私人资料。
