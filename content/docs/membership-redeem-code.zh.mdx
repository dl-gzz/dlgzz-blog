## 当前会员方案

目前推荐在知识星球完成付费，再由管理员发放一次性会员兑换码。网站和微信小程序共用同一份会员权益。

会员权益包括：

- 使用全部 OneWorkOS 知识库
- 解锁网站与小程序会员文章
- 每月 1000 次知识检索
- WorkBuddy 与小红书知识能力
- 官方图片、资料出处和视频入口
- 云端知识持续更新
- 新增知识包自动开放

## 兑换码说明

- 每枚兑换码只能绑定一个账号
- 兑换前先确认当前登录的是你准备长期使用的账号
- 兑换结果和有效期以账号页面显示为准
- 不要公开或转发尚未使用的兑换码

## 绑定微信小程序

在网站“会员与 OneWorkOS”页面生成小程序绑定码，然后在小程序“我的”页面完成微信登录并输入绑定码。绑定后，小程序会读取同一网站账号的会员状态，不需要再次付费。

## 更换电脑

会员权益属于账号。更换电脑后，用同一账号登录，再重新安装并连接 WorkBuddy 即可，不需要重新购买会员。

<Callout type="warn">
如果你有多个邮箱账号，请先确认会员绑定在哪个账号下，再进行兑换或购买。
</Callout>
