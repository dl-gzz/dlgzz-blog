## 连接前检查

- 已安装并能正常打开 WorkBuddy、豆包或龙虾
- 已登录 OneWorkOS 账号
- 会员状态有效，或已经准备好兑换码
- 网络能够打开 `www.dlgzz.com`

## 第一步：下载通用安装包

1. 打开 [OneWorkOS 连接页面](/onework)或 [OneWorkOS 设置](/settings/onework)
2. 点击“下载通用安装包”
3. 将 ZIP 交给当前 AI 客户端读取
4. AI 根据包内 `manifest.json` 选择对应的客户端入口

一个包同时包含 WorkBuddy、豆包和龙虾的安装说明与配置，不需要复制长指令。

## 第二步：按客户端安装

### WorkBuddy

在 WorkBuddy 的“技能/插件 → 插件市场”导入包内的 WorkBuddy 市场 ZIP，安装并启用 `one-worker-os@one-worker-os-marketplace`。

### 豆包

在豆包或火山方舟的 MCP / 自定义 MCP 入口导入包内 `adapters/doubao/mcp.json`。

### 龙虾（OpenClaw）

在龙虾的 MCP 设置中导入 `adapters/lobster/openclaw.json`，或由 AI 执行：

`openclaw mcp add one-worker-os --url https://www.dlgzz.com/mcp --transport streamable-http --auth oauth`

## 第三步：连接账号

在当前客户端的 MCP 列表中找到 `one-worker-os`，点击“连接”“登录”或“重连”。WorkBuddy 的入口是：

**专家·技能·连接器 → 连接器 → 自定义连接器 → one-worker-os → 连接**

如果已经存在旧连接，请选择“重连”。浏览器打开授权页后：

1. 确认当前登录的是拥有会员权益的账号
2. 查看请求的授权范围
3. 由你本人点击“允许连接”
4. 返回 WorkBuddy 等待连接完成

同一会员账号同一时间只保留 1 个有效的 one-worker-os OAuth 连接。如果账号已有连接，授权页会显示“允许并替换”；只有本次令牌交换成功后，旧位置才会在下一次请求时失效。网站登录、会员权益和云端知识不受影响。

## 第四步：测试

连接成功后，可以直接在当前 AI 客户端中说出目标：

- “我想连接 WorkBuddy 的 QQ 邮箱，请告诉我下一步。”
- “我想使用 WorkBuddy 制作 PPT，从哪里开始？”
- “怎么设置每天自动生成日报？”
- “请检索小红书店铺发货的官方教程并标注出处。”

## 常见连接问题

<Accordions>
<Accordion title="看不到 one-worker-os 连接器">

确认通用包已经被当前客户端导入并保存。WorkBuddy 必要时重新打开应用；豆包或龙虾请刷新 MCP 列表。

</Accordion>

<Accordion title="网页授权完成，但 WorkBuddy 仍未连接">

回到 WorkBuddy 的 `one-worker-os` 连接器点击“重连”。不要手动打开网站的 `/mcp` 地址。

</Accordion>

<Accordion title="提示会员或权限不足">

确认网页授权时登录的账号与购买或兑换会员的账号一致，并在 [OneWorkOS 设置](/settings/onework)检查会员状态。

</Accordion>

<Accordion title="显示旧版连接">

先在账号页面撤销旧版授权，再从 WorkBuddy 当前的 `one-worker-os` 连接器重新连接。

</Accordion>
</Accordions>

密码、验证码和授权链接不要粘贴到普通聊天内容中。
